# HX model catalog notice

`hx-catalog.gen.ts` is generated by `scripts/build-hx-catalog.mjs` from the
catalog published by [retr0h/toneharness](https://github.com/retr0h/toneharness),
which that project extracted from HX Edit 3.82's own model database.

It lists, for every HX model, the `@model` id written into `.hlx` files, the
gear it is based on, its DSP cost, and each parameter's real key, label, type,
range, default and unit.
